# Глоссарий переводов Glafira for PostgreSQL

Единые решения по терминам и стилю для словарей `src/locales/en.json` и `src/locales/ru.json`.
Эталон ключей и параметров — `en.json`, эталон смысла — `ru.json`.
Меняя решение здесь, исправьте его в обоих словарях и в `docs/guide/*` одним коммитом.
Сейчас языков два — en и ru; остальные вернутся на этапе P6 (столбец в таблицах и правила письма — вместе с языком).

## Общие правила
- Коротко и нейтрально, как в системных приложениях. Без восклицаний и шуток.
- Параметры `{{…}}` и теги `<code>…</code>` переносятся без изменений: их нельзя переводить, склонять или удалять.
  Порядок внутри фразы можно менять.
- Значение параметра (имя подключения, папки, узла, базы) не склоняется: ставьте перед ним существительное
  в нужном падеже и берите имя в кавычки языка: en `folder “{{name}}”`, ru `папка «{{name}}»`.
- Многоточие — один символ `…`, не `...`.
- Тире в паузе — `—` с пробелами, в диапазонах — `–`.
- Единицы: `ms`, `KB`, `MB` как в en; число и единица разделяются неразрывным пробелом там, где он уже есть в en.
- Плюралы: заполняются все формы языка (см. раздел «Плюралы» в [README](README.md)), даже если формы совпадают по тексту.
- Нерусские термины в ru не склоняются: ставьте перед ними родовое слово («роль Leader», «режим prod», «после switchover»).

## Не переводится
Glafira, PostgreSQL, Patroni, WAL, LSN, DCS, REST API, DNS, TCP, TLS, SSL, mTLS, PEM, JSON, CSV, SQL, ID;
`psql`, `patronictl`, `~/.pgpass`; имена параметров и объектов PostgreSQL и Patroni (`wal_level`, `max_connections`,
`pg_stat_replication`, `pg_monitor`, `pg_catalog`); команды, пути, адреса (`localhost:5432`, `patronictl switchover`);
названия ОС и хранилищ: Keychain, Credential Manager, Secret Service;
роли узла в подписях интерфейса: Leader, Primary, Sync, Quorum (см. «Термины PostgreSQL и Patroni»);
значения окружения: local, dev, test, stage, prod (в ru — строчными, как в en).

## Стиль по языкам

| Язык | Обращение | Кнопки и пункты меню | Вопрос-подтверждение | Кавычки | Особенности |
|---|---|---|---|---|---|
| en | без обращения; в крайнем случае «you» | глагол в повелительном: Save, Delete | `Delete folder “{{name}}”?` | “…” | регистр предложения (sentence case) во всех подписях, включая заголовки и кнопки |
| ru | без обращения, по возможности; иначе «вы» | инфинитив: Сохранить, Удалить | `Удалить папку «{{name}}»?` | «…» (вложенные „…“) | буква «ё» пишется там, где она есть («повреждён», «подтверждённый»); регистр предложения; «prod», «primary», «switchover» — латиницей |

## Термины PostgreSQL и Patroni

| en | ru | Примечание |
|---|---|---|
| connection | подключение | Профиль подключения в дереве; «соединение» не использовать |
| server | сервер | Вид подключения «Сервер» — один PostgreSQL |
| host list | список узлов | Вид подключения «Список узлов»: несколько серверов, primary определяется автоматически |
| node / member | узел / участник | «Узел» — любой сервер кластера (раздел «Узлы» в дереве); «участник» — запись `members[]` Patroni, когда речь о данных Patroni |
| cluster | кластер | |
| Patroni cluster | кластер Patroni | Вид подключения «Кластер Patroni» (адреса REST API Patroni) |
| leader | лидер | В тексте — «лидер»; подпись роли в интерфейсе — `Leader` (в ru тоже латиницей) |
| primary | primary | Не переводится, в тексте строчными; подпись роли в списке узлов — `Primary` |
| replica | реплика | |
| sync standby / quorum standby | Sync / Quorum | Так подписываются роли; в тексте — «синхронная реплика» / «кворумная реплика» |
| lag | лаг | Отставание реплики от primary; в байтах (`16 MB`) или во времени |
| replay delay | задержка replay | `replay` не переводится |
| timeline | таймлайн | В узких подписях — `TL` |
| failover, switchover | failover, switchover | Не переводятся и не склоняются; в кнопках — `Switchover…`, `Failover…`, в журнале — «Отмена switchover» |
| restart | restart / перезапуск | Действие Patroni в подписях кнопок, окон и журнала — `Restart` (не склоняется, как switchover); состояние участника — по-русски: «нужен перезапуск» |
| pause | пауза | Кластер Patroni на паузе — «Patroni на паузе» |
| replication slot | слот репликации | |
| WAL | WAL | «журнал предзаписи» не использовать |
| database | база данных / БД | В тексте и подписях — «база данных» (мн. «базы данных», «базы»); «БД» — только там, где не хватает места |
| schema | схема | |
| table | таблица | |
| view | представление | |
| materialized view | материализованное представление | В узких подписях — «мат. представление» |
| function | функция | |
| sequence | последовательность | |
| partition | партиция | Партиционированная таблица — «партиционированная» |
| role | роль | Роль PostgreSQL (`pg_monitor`); роль узла в кластере (Leader, Replica) — «роль узла», чтобы не путать |
| extension | расширение | |
| catalog | каталог | Системные каталоги PostgreSQL (`pg_catalog`) и дерево объектов баз; группа подключений в дереве — «папка», не «каталог» |
| readiness checklist | чек-лист готовности | Проверка подключения: что готово для диагностики, а что нет |
| connection string | строка подключения | JDBC, `postgresql://…`, `host=… port=…` |
| read-only | только чтение | Как в `common.readOnly`; «только для чтения» там, где нужна грамматика фразы |
| environment | окружение | Значения (local, dev, test, stage, prod) не переводятся |
| prod connection | prod-подключение | `prod` — только как значение окружения |
| keychain / secret store | хранилище секретов | Полностью — «системное хранилище секретов» (как в `errors.secrets.keychain`); названия Keychain, Credential Manager, Secret Service — латиницей |
| xmin horizon | горизонт xmin | Самая старая транзакция, снимок которой ещё нужен; `xmin` не переводится. Кто держит горизонт — «держатель» |
| idle in transaction | idle in transaction | Состояние сессии, не переводится и не склоняется: «сессия в состоянии idle in transaction» |
| wait event | событие ожидания | `wait_event`; тип `wait_event_type` — «класс ожидания» (Lock, IO, CPU* и другие названия классов не переводятся) |
| root blocker | корневой блокирующий | Сессия, которая держит других и сама ничего не ждёт; ждущие за ней — «жертвы» |
| queued DDL | DDL в очереди | DDL, который ждёт блокировку отношения и сам задерживает других |
| retained WAL | удерживаемый WAL | Сколько WAL не даёт удалить слот; в узком столбце — «Удерживает WAL» |
| failover readiness | готовность к failover | Вердикт по каждому кандидату: готов ли принять роль лидера |
| health matrix | матрица health | Коды ответов адресов проверки здоровья Patroni; `health` не переводится |

| organization policy | политика организации | Пометка «задан вашей организацией» там, где значение закреплено политикой |
| system default (…) | как в системе (…) | |
| hint (значок «?») | подсказка | |
| wait profile | профиль ожиданий | Инструмент диагностики: на что тратят время активные сессии |
| finding | находка | Результат правила диагностики: строгость, заголовок, «что сделать» |
| action | действие | То, что приложение меняет по кнопке: отмена запроса, завершение сессий, удаление слота, действия Patroni; не «операция» |
| cancel a query / terminate a session | отменить запрос / завершить сессию | `pg_cancel_backend` — «отмена запроса», `pg_terminate_backend` — «завершение сессии»; «убить» не использовать |
| actions journal | журнал действий | Файл `actions.jsonl` и вкладка «Журнал действий»; не путать с «журналом событий» топологии в обзоре |
| preview | предпросмотр | Окно действия, которое заново читает данные и показывает, что будет сделано, а что нельзя и почему |
| batch | пакет | Действие над несколькими сессиями по условию («idle in transaction старше N минут»), а не по выбору строк |
| progress (of an action) | ход действия | Панель шагов после действия Patroni до «Готово»; в en — `Progress` |
| unknown outcome | неизвестный исход | Запрос Patroni ушёл, ответа нет: приложение его не повторяет, выполнилось ли действие, показывает ход действия |
